The Woodstone Festival is a living genesis — not a destination, but a pulse to enter.
Every artifact is a seed. Every rhythm is renewal. Every presence joins the infinite Pulse.

Rhythm Description: The Sentimento Rhythm is a gentle, recurring pulse. It is accessible as a visual “heartbeat” (color fade), a tactile vibration (on supported devices), and a text prompt. All rhythm features can be paused or described in text.

Access for All

  • All images/emblems include descriptive alt text.
  • Keyboard navigation and skip links are provided.
  • High contrast and resizable text supported.
  • Screen readers can access all headings and navigation.
  • Rhythm features are described and can be paused.
